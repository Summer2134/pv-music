# PV Music · кнопки плеера

16 оригинальных геометрических значков. PNG 128×128, прозрачный фон,
цвет #F4F5F8, единая толщина контура 1.9 в сетке 28×28.
Исходники — отдельные SVG в `source/`; сборка из корня репозитория:

```sh
node music/assets/icons/source/build.mjs
```

Нужна существующая зависимость проекта @resvg/resvg-js. Можно передать
PV_ICON_DEPS — путь к package.json установки с этой зависимостью.
Скрипт экспортирует PNG и docs/music-icons-preview.png (16/24/48 px).

Названия точно соответствуют docs/codex/music-player.md. loop_track использует
стандартную цифру 1 внутри стрелок; loop_off — перечёркнутый повтор,
loop_queue — повтор всей очереди, autoplay — бесконечность.
like — контур сердца, liked — заполненное сердце.

Генерация изображений не использовалась: для строгой геометрии UI значки
нарисованы в SVG и растрированы. Код бота и подключение эмодзи не менялись;
подключение выполняет Claude как эмодзи приложения PV Music.
